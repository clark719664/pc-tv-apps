Setup and requirements

Windows and Linux

Keep your computer awake and on the same network as your TVs. Pro and Lite require a computer.

  1. Download the Windows installer or Linux x86_64 archive. Linux requires Ubuntu 22.04, Debian 12 or newer.
  2. Run the installer. On Linux, run ./install.sh; add --service to start at boot. Administrator rights are not required.
  3. Choose a TV in the app and follow its pairing instructions.

Builds are not code-signed. Windows SmartScreen may warn you; check the release checksums before installing.

Roku TVs are supported. Fire TV, Chromecast, AirPlay and DLNA support is in beta.

Mobile beta

Live and Remote run without a PC. Android requires version 7 or later; Remote also requires a 64-bit device. Download the APK and allow installation from your browser when prompted.

For Live on iPhone, open the web app in Safari, then choose Share → Add to Home Screen.

Mobile Live has a smaller channel selection, search and favorites. It needs internet and does not include the desktop program guide or TV casting.

Android Remote needs the same Wi-Fi as your TV. TV compatibility needs real-device testing. An iPhone remote is not available.
